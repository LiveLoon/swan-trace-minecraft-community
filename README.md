服务器原则不能通过投票的方式进行修改

1. **禁止恶意破坏服务器运行**

严禁 DDoS 攻击、漏洞利用、刷屏/炸服等任何危害服务器稳定性的行为。情况严重者将追究法律责任（破坏服务器运行）。

包括不限于群内/游戏内禁止辱骂、歧视、政治敏感内容（影响玩家的游玩体验）。

4. **适度的红石**

为避免卡服，请避免建造超大规模高频红石（破坏服务器运行）。

5. **影响玩家游玩**

包括不限于恶意破坏与侵占、视线阻挡、恶意追击玩家（影响玩家的游玩体验）**。

6. **挂机（AFK）与实体压迫**

若因挂机导致服务器资源耗尽或卡顿，管理员有权直接踢出或清除该玩家实体和资源（破坏服务器运行）。

7. **恶意宣传或者贬低 鸿迹（Swan Trace）社区和服务器**

在没有任何有效的证据下恶意宣传和贬低鸿迹（Swan Trace）服务器。

**总结：底线就是不破坏服务器的运行和不影响玩家的游玩体验，你可以做你任何想要做的事情。**
